Music Box – Plugin phát nhạc ngay trong server minecraft của bạn

>>>

Music Box là plugin phát nhạc cá nhân dành cho server Minecraft chạy Core Paper như Paper, Purpur, Leaf. Người chơi chỉ cần dán link file nhạc trực tiếp, đặt cho nó một ID ngắn rồi phát bất cứ lúc nào bằng một câu lệnh. Âm thanh được truyền qua Simple Voice Chat nên nghe như đang bật loa ngay trong game, người ở gần còn nghe được nếu họ cho phép.

Điểm nổi bật

  • Kho nhạc cá nhân: mỗi người chơi tự thêm tối đa 20 bài (có thể chỉnh trong config), admin không bị giới hạn.
  • Phát nhạc từ link trực tiếp: hỗ trợ mp3, ogg, wav, tự nhận diện định dạng bằng nội dung file chứ không tin vào đuôi file.
  • Kho nhạc global: admin thêm bài dùng chung, ai cũng phát được bằng một lệnh.
  • Phát khi đang tải: không cần chờ tải xong cả file, chỉ đệm vài giây đầu là phát.
  • Nghe nhạc người khác: người chơi ở gần (mặc định 24 block) nghe được nhạc bạn phát, ai không thích có thể tắt trong menu cài đặt.
  • Lặp lại thông minh: lặp danh sách phát, lặp một bài hoặc phát ngẫu nhiên.
  • Menu cài đặt trong game: bật tắt nghe nhạc người khác, lặp lại, đổi chế độ phát, hủy nhạc chỉ với vài cú click.
  • Tiết kiệm băng thông: cache file trên đĩa, nghe lại cùng link không tốn thêm dữ liệu, tải trùng được gộp lại, dừng nhạc là ngắt tải ngay.
  • Kiểm tra link khi thêm: link hỏng, trang web hoặc file không hỗ trợ sẽ bị từ chối ngay lúc /musicbox add.
  • Tự đổi link chia sẻ: link GitHub (blob), Dropbox và Google Drive được tự chuyển sang link tải trực tiếp.
  • An toàn: chặn link trỏ tới IP nội bộ, có hệ thống cấm người chơi, giới hạn dung lượng và thời lượng bài.
  • Tùy biến toàn bộ thông báo bằng tiếng Việt, hỗ trợ mã màu &.

Yêu cầu

Phía server

  • Core Paper hoặc nhánh của Paper như Purpur, Leaf, phiên bản 1.21 trở lên.
  • Java 21 trở lên.
  • Plugin Simple Voice Chat (bản dành cho Bukkit/Paper) - bắt buộc. Thiếu plugin này thì Music Box sẽ tự tắt khi khởi động.
  • Mở cổng UDP của Simple Voice Chat trên server (mặc định 24454) để người chơi kết nối được voice chat.

Phía người chơi

  • Cài mod Simple Voice Chat trên máy (bản khớp với phiên bản Minecraft) rồi vào server. Chưa có mod sẽ không nghe được nhạc.
Tải Simple Voice Chat tại: [Modrinth]

Cài đặt

  • Bước 1: Cài Simple Voice Chat lên server và kiểm tra voice chat hoạt động.
  • Bước 2: Bỏ file MusicBox.jar vào thư mục plugins.
  • Bước 3: Khởi động lại server (không nên dùng /reload).
  • Bước 4: Plugin tự tạo thư mục plugins/MusicBox gồm config.yml, dữ liệu người chơi và thư mục cache.
  • Bước 5: Chỉnh config nếu cần rồi dùng /musicbox reload để áp dụng.

Cách sử dụng

1. Chuẩn bị link nhạc

Bạn cần một link trực tiếp tới file nhạc (mp3, ogg hoặc wav), ví dụ link từ catbox.moe, GitHub, Dropbox, Google Drive hoặc archive.org. Link dẫn tới trang web thông thường hoặc file FLAC sẽ bị từ chối. Lưu ý: cần add các link lưu trữ nhạc trong config, mặc định có sẵn catbox.moe

2. Thêm bài hát

/musicbox add {id} {link}
Ví dụ: /musicbox add lofi https://files.catbox.moe/abc123.mp3
  • ID chỉ gồm chữ thường, số, dấu gạch dưới hoặc gạch ngang, tối đa 32 ký tự.
  • Không dùng ID all vì đã được giữ riêng.
  • Plugin sẽ kiểm tra link trước, hợp lệ mới lưu.

3. Phát và dừng nhạc

  • /musicbox play {id} - phát bài trong kho cá nhân.
  • /musicbox global {id} - phát bài trong kho global.
  • /musicbox cancel - dừng nhạc đang phát.
  • /musicbox list - xem danh sách bài cá nhân và bài global.
  • /musicbox del {id} - xóa bài cá nhân.

4. Cài đặt cá nhân

Gõ /musicbox setting để mở menu:
  • Nghe nhạc người khác: bật hoặc tắt việc nghe nhạc do người chơi ở gần phát.
  • Lặp lại bài cá nhân: bật thì bài tự phát tiếp, tắt thì chỉ phát một lần.
  • Chế độ phát lại: lặp danh sách phát, lặp bài đang phát hoặc phát ngẫu nhiên.
  • Hủy nhạc hiện tại: dừng ngay bài đang phát.

Lệnh dành cho quản trị viên

  • /musicbox reload - tải lại config.
  • /musicbox clearcache - xóa toàn bộ cache nhạc đã tải.
  • /musicbox globalmusic add {id} {link} - thêm bài vào kho global.
  • /musicbox globalmusic del {id} - xóa bài global.
  • /musicbox globalmusic list - xem danh sách bài global.
  • /musicbox delplayer {player} {id hoặc all} - xóa bài của người chơi.
  • /musicbox ban {player} - cấm người chơi dùng Music Box.
  • /musicbox unban {player} - gỡ cấm.
Lệnh có thể gọi ngắn bằng /mbox.

Quyền hạn (Permission)

  • musicbox.use - dùng các lệnh cơ bản, mặc định bật cho mọi người.
  • musicbox.admin - dùng lệnh quản trị, không bị giới hạn số bài, mặc định chỉ OP.

Cấu hình nhanh

Các mục thường chỉnh trong config.yml:
  • settings.max-songs-per-player: số bài tối đa mỗi người (mặc định 20).
  • settings.max-file-size-mb: dung lượng file tối đa (mặc định 30 MB).
  • settings.max-duration-seconds: thời lượng tối đa mỗi bài (mặc định 600 giây).
  • settings.allowed-domains: giới hạn tên miền được phép, để trống là cho mọi tên miền.
  • settings.verify-on-add: kiểm tra link khi thêm bài.
  • settings.max-concurrent-downloads: số lượt tải chạy cùng lúc (cần khởi động lại server để đổi).
  • cache.max-size-mb và cache.ttl-hours: dung lượng và thời gian lưu cache.
  • audio.distance và audio.volume: khoảng cách nghe và âm lượng.

Lưu ý

Plugin chỉ hỗ trợ định dạng mp3, ogg và wav. File FLAC, link trang web hoặc link yêu cầu đăng nhập sẽ không phát được.
File config.yml cũ trên server không tự bị ghi đè khi nâng cấp, hãy so sánh với bản mới nếu muốn dùng các tùy chọn mới.
Người chơi chưa cài mod Simple Voice Chat sẽ nhận thông báo và không nghe được nhạc.
