My Server Manager

Miễn phí

My Server Manager là phần mềm miễn phí giúp tạo và quản lí nhiều server Minecraft Java trên Windows và Linux: Paper, Purpur, Leaf, Fabric, nhập server từ file .jar, tên và mô tả có màu, không cần dòng lệnh.

Giới thiệu My Server Manager

My Server Manager là phần mềm giúp bạn tạo và quản lí nhiều server Minecraft Java ngay trên máy tính của mình, không cần dùng dòng lệnh. Chọn phần mềm server, chọn phiên bản, bấm tạo là app tự tải mọi thứ cần thiết, kể cả đúng bản Java cho từng server, nên bạn không phải cài Java.

Điểm nổi bật

  • Tạo server nhanh: Vanilla, Paper, Purpur, Folia, Leaf, Fabric, Velocity hoặc file .jar tự chọn.
  • Nhập server từ file .jar: chọn file, chọn phần mềm (Paper, Purpur, Leaf…) và phiên bản là xong.
  • Tên và mô tả có màu: gõ mã màu & hoặc § để tô màu tên và mô tả (MOTD) server, có bảng chọn màu và xem trước ngay.
  • Điều khiển và theo dõi: chạy, dừng, khởi động lại, console realtime có gợi ý lệnh, Dashboard cho nhiều server cùng lúc.
  • Plugin và mod: tìm, cài và gỡ trực tiếp từ Modrinth.
  • Quản lí tệp: duyệt, đổi tên hàng loạt, di chuyển, xóa và sửa tệp bằng trình sửa tích hợp.
  • Cho bạn bè vào chơi: hướng dẫn IP tùy chỉnh và hỗ trợ playit.gg.
  • Chạy ổn định: thu xuống khay hệ thống, tự khởi động server, tự khởi động lại khi crash, thoát an toàn.
  • Đa ngôn ngữ: tiếng Anh, tiếng Việt và song ngữ Việt-Anh.
  • Riêng tư: không tài khoản, không thu thập dữ liệu.

Bắt đầu nhanh

  1. Mở app, bấm Tạo server (hoặc Nhập máy chủ từ tệp .jar nếu bạn đã có file server).
  2. Đặt tên, chọn phần mềm và phiên bản, chọn RAM rồi tạo.
  3. Đồng ý Minecraft EULA khi app hỏi, sau đó bấm Start.
  4. Muốn bạn bè vào chơi cùng, mở trang Địa chỉ IP để thêm địa chỉ tùy chỉnh hoặc dùng playit.gg.

CHÍNH SÁCH QUYỀN RIÊNG TƯ VÀ LƯU Ý

1. Dữ liệu cá nhân
Ứng dụng không thu thập dữ liệu cá nhân, không phân tích, không theo dõi, không gửi số liệu sử dụng, không quảng cáo và không cần tài khoản. Mọi dữ liệu (server, cài đặt, nhật ký, bản Java đã tải) được lưu ngay trên máy của bạn.

2. Kết nối mạng
Ứng dụng chỉ kết nối tới các dịch vụ cần thiết cho việc bạn yêu cầu: GitHub (cập nhật app, tệp dữ liệu, ngôn ngữ), Mojang, PaperMC, Purpur, Leaf, Fabric (danh sách phiên bản và tải server), Modrinth (plugin, mod), Adoptium (tải Java) và playit.gg (chỉ khi bạn bật). Các dịch vụ này có thể thấy địa chỉ IP của bạn như mọi yêu cầu qua internet.

3. Minecraft EULA
Server chỉ chạy được sau khi bạn chấp nhận Minecraft EULA. Ứng dụng mở EULA để bạn đọc và không tự chấp nhận thay bạn.

4. Không liên kết
Đây không phải sản phẩm chính thức của Minecraft, không được Mojang hay Microsoft phê duyệt hay liên kết. Mọi tên sản phẩm được nhắc đến thuộc về chủ sở hữu tương ứng.

5. Gỡ cài đặt
Gỡ cài đặt ứng dụng không xóa server của bạn, trừ khi bạn chọn xóa toàn bộ dữ liệu.
